# 市综合模拟

入口：https://nishiyu0411-alt.github.io/word/exam/

三个版本：随机60题 / 60分钟；60题加120道心理问卷 / 75分钟；随机60题不限时练习。计分题库730道，练习模式另有69道上海行测补充题。心理原库187题，完整版每次抽120题，保留原选项，不计分，不生成心理测评结论。

逻辑库215题和word首页217题全部收录，可在“全部题库”按来源、题号、知识类别检索。逻辑库199道有效选择题参与组卷，14道开放题、2道疑题保留原文和原参考答案；word首页200道完整题全部参与组卷，涵盖语言、错句、教育学、法规和常识等，另17道缺损题保留在待核验区。二、三、五选项原题直接支持，保留完整选项，不补造选项。之前的考试存档可兼容本次元数据更新。

## 规则

- 考试全部作答后才能主动提交，期间隐藏对错和解析；到时自动交卷，未答题单独统计为未得分。
- 五类题型按可调整的模拟权重抽取，默认逻辑30%、数学30%、错句10%、语言20%、综合知识10%。不是官方出题概率。题型耗尽后按其他已选题型的权重补足。同卷不重复，新卷优先选取近期未做题。
- 暂停保存试卷、答案、当前位置、标记与剩余时间；关闭或刷新自动存档并暂停。切换标签仍计时。
- 每种模式独立保留一份未完成试卷；保留最近5次已交卷试卷。浏览器本地存储，不上传答案。
- 可导出、导入单套试卷JSON，在不同设备间转移进度。导入仅接受未被修改的已知题目。
- 练习提供可拖动、可收起的悬浮当前时钟与可选闹钟提醒，不使用考试倒计时；每题作答后可主动查看解析。
- 数字键1—8或字母A—H选择原题选项；左右方向键切题。页面背景获得焦点时可用空格标记。

## 部署

本目录为独立静态应用，放入 GitHub Pages 的 `exam/` 目录即可。原仓库其他页面不需要修改。无构建依赖，全部题目打包在 `data.js`，不依赖跨域实时加载原题库或第三方图片。

## 开发与核验

使用Node.js 20或以上。进入本目录后运行：

```sh
node --test tools/core.test.mjs
```

需要刷新题库时运行：

```sh
node tools/fetch-sources.mjs
node tools/build-bank.mjs
node --test tools/core.test.mjs
```

源文件保存在被忽略的 `sources/` 临时目录。重新导入前应核对来源结构；行测原材料的适用题号范围在导入脚本中明确指定，禁止让共享材料自动沿用到后面的独立题。`tools/bank-report.json` 记录筛选结果。公开题库后续变化可能导致题数变化，检查报告后再发布更新。
