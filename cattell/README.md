# 卡特尔 16PF 人格练习

根据所提供的《职业素质卡特尔人格.xls》制作的静态练习页面，保留 187 道题目、原题号、选项和 16 项因素的计分关系。

## 使用

部署在当前仓库的 `cattell/` 目录，访问 GitHub Pages 对应的 `/word/cattell/` 页面。无需构建或安装依赖。

- 日常练习：全部、未作答、收藏、聪慧性题、错题回练、计分待核对，支持因素筛选与随机排序。
- 快捷键：1、2、3 或 A、B、C 选择；左右方向键切题；空格收藏。
- 完整测验：独立保存 187 题的作答与前台累计时间，交卷前隐藏计分，未完成时提示漏答。
- 报告：整套完成并选择原表男女常模后，显示原始分、标准分与原表评级。
- 保存：浏览器自动保存、JSON 导入导出、文本报告导出、本机记录清空。
- 跨设备：相同同步码合并记录；与旧刷题 App 使用不同的记录标识。同步码不写入导出文件或云端记录。同步内容经 PBKDF2（SHA-256，210000 次）派生密钥和 AES-GCM 加密。请自行保管同步码。

## 资料与计分

本页面用于熟悉所提供练习资料中的题型，不代表上海考试官方题库、合格线或心理诊断。人格自述题不判对错；错题回练只收录计分键无已知疑点的聪慧性题。

1. 第 1、2、187 题不计分，其余 184 题按 Excel 实际公式计分。
2. 第 11、12、34、35、41、60、61、62、63、64、161、162 题，原表公式将 A 计为 1 分，但分值表显示 0 分。此处沿用 Excel 公式，并在题内标注。
3. 第 127、153 题的原表计分键存在疑点，保留原表计分并标记为待核对，不收录进错题回练。
4. 男性忧虑性 O 的常模遗漏原始分 19 分。遇到该分数显示“原表未给出”，不补造标准分。
5. 低、中、高评级沿用原表报告页公式，与常模分段分别展示。

题库与换算数据位于 `data.js`。验证时将 33 组完整作答与原表 BIFF 实际公式独立计算的结果比对，覆盖男女评级、未完成情况、常模缺口及跨设备记录合并；同步通过临时加密测试记录验证读写与恢复，测试记录已删除。
